Release notes

7.6.3November 2026
  • The view cube controls the camera in 3D: tapping a face looks from the top, front or side; dragging the cube orbits the 3D stage.
  • A “2D” button returns from the 3D view to the plot.
  • My layout: an “Edit” button and edit mode; tools and the plot stay locked while editing.
7.6.2November 2026
  • The view cube is larger and can be rotated by dragging; every face can be tapped.
  • Horizontal and vertical layout for tool boxes.
  • Fixed sideways overflow on phones with long project names.
7.6.1November 2026
  • The app is now called LampOff; projects and settings from earlier versions move over automatically.
  • The desktop app migrates user data to the new folder.
7.6.0November 2026
  • Illustrated A–Z user guide, in the app and as a PDF.
  • View cube; x, y, z editing in front and side views.
  • Upright towers and pipes at any angle.
  • Grouped context menu; manual dimension values.
  • My layout: free-floating tool boxes; layout settings.
