LampOff 7.11.0

Download and installation

LampOff is free. Every platform uses the same project file, so a plot prepared on one device opens on another.

Android

LampOff for Android phones and tablets is distributed through Google Play.

Google Play · coming soon
Requires
Android 6.0 or later
Distribution
Google Play
Internet
Only for the online library

Until the Google Play release, the web app offers the same features on a phone.

iPhone and iPad

On iPhone and iPad, LampOff runs as a web app added to the Home Screen from Safari and opens full screen from its own icon.

Open in Safari
Requires
Current iOS and iPadOS, Safari
Install
Safari › Share › Add to Home Screen
Offline
Works without internet after the first visit

Projects are stored on the device; export a .json file for backup.

Windows

The Windows app adds a large-screen workspace, a live console connection over Art-Net and sACN, and a test console.

Download for Windows
Requires
Windows 10 and 11, 64-bit
Install
LampOff-Setup .exe; install folder can be chosen
Updates
New versions are announced in the app

The installer is downloaded from the GitHub releases page.

macOS

The macOS app has the same features as the Windows version: large screen, Art-Net and sACN, test console.

Download for macOS
Requires
macOS 12 or later
Install
LampOff .dmg; drag to Applications
First launch
On a security prompt: Finder › right-click › Open

The installer is downloaded from the GitHub releases page.

Web

The web app needs no installation; it opens in current browsers and keeps working without an internet connection after the first visit.

Open the web app
Browsers
Chrome, Edge, Safari, Firefox
Install
Not required; can be added to the Home Screen
Data
Stored in the browser on this device

The same address works on phone, tablet and computer.
